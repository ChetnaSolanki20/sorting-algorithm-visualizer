# Sorting Algorithm Visualizer (Java)

## Project Overview
This project is a Java-based Sorting Algorithm Visualizer that demonstrates the working of various sorting algorithms through graphical visualization. It is designed to help students understand and compare different sorting techniques.

## Implemented Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort
- Shell Sort
- Radix Sort
- Bucket Sort

## Features
- Graphical visualization of sorting algorithms
- Interactive user interface
- Real-time sorting animation
- Comparison of multiple sorting techniques
- Educational and easy to understand

## Technologies Used
- Java
- Java Swing

## Purpose
This project was developed to provide an interactive learning platform for understanding the behavior and performance of different sorting algorithms.
